# LaTeX

Use an installed Unicode-capable engine and its maintained Hebrew/bidi language support, Hebrew-capable fonts and explicit LTR spans for code/math/technical identifiers. XeLaTeX/LuaLaTeX package behavior and supported font selection differ. Check the actual compiler/package set before choosing a recipe; do not reverse the `.tex` source. Compile and inspect the PDF and extraction separately. No LaTeX engine or package combination was tested in the current run.
