04 / GIVE YOUR AI A BETTER DEFAULT

One prompt.
A better direction.

Ask your skill-capable AI to install RTRTL. It reads a compact core and opens a format recipe only when the task needs it.

Manual install & other agents ↗
PASTE INTO CODEX

Use $skill-installer to install RTRTL from https://github.com/OriAshkenazi/RTRTL/tree/main/skills/rtrtl. Preserve any existing local skill edits. Verify that SKILL.md and its relative references are installed. Then use $rtrtl for Hebrew and mixed Hebrew/English content.

No account or API key for the skill. Host permissions still apply. Other agents need their own configured skills directory. If Codex does not discover it, start a new turn or restart.
